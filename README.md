# Legal TG Bot

Telegram-бот на Go для записи пользователей на консультации к юристам.

Бот позволяет пользователю зарегистрироваться, выбрать юриста, посмотреть доступные слоты и записаться на консультацию. Взаимодействие с пользователем реализовано через Telegram Bot API и inline-клавиатуры.

## Возможности

* регистрация пользователей;
* получение списка юристов;
* выбор юриста через inline-клавиатуру;
* просмотр доступных слотов;
* запись на консультацию;
* обработка callback-запросов;
* управление состоянием диалога пользователя через FSM;
* хранение данных в PostgreSQL;
* структурированное логирование.

## Технологии

* Go
* PostgreSQL
* Telegram Bot API
* Docker
* FSM
* slog

## Архитектура

Приложение разделяет обработку Telegram-событий и работу с данными.

FSM используется для управления последовательностью действий пользователя при записи на консультацию.

## Запуск

Проект запускается в Docker.

```bash id="h5s5t9"
docker compose up --build
```

Конфигурация приложения задаётся через переменные окружения.

## Цель проекта

Проект использовался для практики разработки Telegram-ботов на Go, работы с PostgreSQL, обработки callback-запросов и построения многошаговых пользовательских сценариев.
